我的 Frontend 之路

我最早开始接触前端，就是为了最一个自己的博客。当时什么都不懂，不知道git，不知道node.js，不知道html/js/css，于是上网到处找搭建博客的教程。

那时候大模型还没兴起，网上大多的教程文章和视频都是手把手教你搭建的，其中讲的较多、搭建过程简单的就是 hexo 了。

很快我有了自己的博客，随后便有了自定义的想法，然后就是找自己喜欢的主题，在自己慢慢改，在这过程中，我几乎是一边翻文档，一边改，一边踩坑，一边上网查资料，慢慢的就有了自己的前端基础。

ParticleXF 的前世今生

我最早用的就是 ParticleX 主题，作者Argvchs在自己的博客上写了很多教程，我在他博客询问了几个问题他也很详细的给了我解答，给了我很多帮助。

再后来，我的博客陆陆续续写了三年，期间还全部重做了几次，但是主题一直都是 ParticleX，在此之上加了很多自定义的功能，ParticleX 的结构已经被我改得面目全非了，没有一个文件是原始的了。

于是前不久，在我给 ParticleX 做了样式的大更改之后，我决定把我改后的主题叫作 ParticleXF 并发布出来。

HEXO tutorial 系列

在发布时，hexo 官方要求主题要有一个演示网站，但我觉得演示网站不能光秃秃的吧，于是打算自己写几篇教程文章，教大家如何从零开始搭建自己的博客。

其实在写的过程中，真的感触颇深，当初我也是靠着前辈们的教程一路走来的，如今我再写我自己的教程，这是一种传递精神。

Deep Thinking

其实现在的 AI、Agent 技术已经完全改变了一个站点的搭建方式，可以说是颠覆了传统的前端开发模式。

一句话就可以让 Agent 帮你搭建一个博客，帮你写出一个主题。但是我为什么还是手写了这个系列的文章，估计是我的固执把。

ParticleX 和 ParticleXF 陪我走过了这三年，我们一起见证了很多，ParticleXF 也是我纯手写的主题，不能说是可贵的精神，但如今算是稀有。
