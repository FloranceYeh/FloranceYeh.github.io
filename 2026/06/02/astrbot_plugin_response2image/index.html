Response2Image 插件开发记录

2026/6/2 开发记录 Python Astrbot

项目背景

一切的开端是 CodeBoy 在群里发了一条消息，说是他有个办法实现超低价的Gpt Image 2，均价一张0.7分钱，对的不是0.7元，是0.007元

于是我开始向他请教，他给我了 CodeBoy2006/responses-images-proxy 这个项目，这个服务会将生图请求路由到 /v1/responses 端点，使用 image_generation 工具来实现生图

使用过程

我在本地服务器上部署了这个服务，转接到我的 AstrBot 上的 Gitee 生图插件，用了一段时间，期间也给 CodeBoy 反馈了很多问题，也给他的仓库 p r了一个 Pretty Log

我也把这个仓库推给了我其他玩 Astrbot 的朋友，但是部署这个毕竟多操作一点，多开一个端口，多跑一个服务，所以我就想能不能直接把这个功能写成一个 AstrBot 插件，省去部署的麻烦

这就诞生了项目的原灵感

开发过程

此外，CodeBoy 还给了我一个html文件，纯前端的版本，通过参考前端版的js代码，很容易就用 Python rewrite 出来

再结合 Codex 大人，很快 Vibe 了一个可用的插件

同时，因为用惯了 Gitee 插件，我也给我的插件加了个自拍模式

主要代码开发完成后，就是各种各样的测试和Debug，增加Feature，优化用户体验等等

如今，插件的版本为 v1.3.1 ，已经算是很完善了，至少满足了我现在的使用需求了

我已经把插件推到了 Astrbot 的插件市场，等待审核

这算是我的第二个正式发布的 AstrBot 插件了，第一个没过审，还有两个项目腰斩了，等我有时间再拾起来（现在快期末了，要准备复习了，我真的想评奖评优，真的要好好学习）

总结

总的来说，这个插件的开发过程还是挺顺利的，感谢 CodeBoy 提供了宝贵的建议和指导

具体的功能和使用方法可以参考插件的 README.md 文件

项目仓库地址：astrbot_plugin_response2image
