My Windows Beautify

2026/5/2 Windows Beautify

美化工具速览

YASB - 顶栏美化工具
komorebi - 窗口平铺管理器
GlazeWM - 窗口平铺管理器
Tacky Borders - 窗口边框美化工具
FloArc - 窗口透明和亚克力磨砂效果工具
Windhawk - Windows定制工具

Wallpaper Engine - 动态壁纸工具

YASB美化顶栏, 高度可自定义, 还有很多好用的插件

GlazeWM是窗口平铺管理器, 支持设置窗口透明度, 类似i3wm的窗口管理方式

komorebi也是窗口平铺管理器, 但是对分层窗口(比如带透明度的窗口)支持不是很好, 但是支持可自定义的窗口边框

Tacky Borders是窗口边框美化工具, 特点是可以设置动态的窗口边框, 还有发光和阴影效果可选

Windhawk是Windows定制工具, 可以修改系统的很多方面, 包括窗口的外观和行为，有很多好用的tweaks

FloArc是我写的窗口透明和亚克力磨砂效果工具
